# pytong-ucze-sie

My first Python exercises: input and output, random numbers and lists, in 5 scripts.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2021 (first commit on 23 February 2021, last commit on 24 February 2021).

## Contents

- `main.py`: asks for a name and an age and prints them back.
- `p2.py`, `p3.py`, `p4.py`, `py5.py`: random numbers and lists.

## Running

```
printf 'Ana\n30\n' | python3 main.py
```

Result on 26 November 2026 (Python 3.14): the script prints `your name is Ana`, asks for the age and prints more lines.
